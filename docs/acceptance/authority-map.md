# Authority map

Who can do what today. Each claim cites the file and function that enforces it. Only the engine promotes;
no model approves anything.

| Actor | Can read | Can write | Can run | Can approve |
|---|---|---|---|---|
| Builder model | Its attempt worktree via Read/Glob/Grep (`src/kickass_loop_engineer/providers/claude_code.py::edit`); a FILE-block builder sees only its brief (`src/kickass_loop_engineer/agents.py::build`). | Edit/Write in the worktree. Changes are policy-checked afterwards and violations reverted (`src/kickass_loop_engineer/workspace.py::harvest`); FILE blocks go through `src/kickass_loop_engineer/workspace.py::apply`. | Bash with any command, no allowlist (`DEFAULT_EDIT_TOOLS` in `src/kickass_loop_engineer/providers/claude_code.py`); Codex gets a workspace-write sandbox (`src/kickass_loop_engineer/providers/codex_cli.py::_argv`). | Nothing. Its output is files; the verdict is the gate's. |
| Reviewer model | A snapshot of the winner's changed files (`src/kickass_loop_engineer/orchestrator.py::_snapshot`); on the Claude CLI also Read/Glob/Grep only (`src/kickass_loop_engineer/providers/claude_code.py::complete`). | Findings text only; the engine files it (`src/kickass_loop_engineer/review.py::write_slice_review`). | No edit or shell tool on the prose path. | Nothing: a review has no approved flag (`src/kickass_loop_engineer/agents.py::Review`). It blocks only if `review.block_on` is set (`src/kickass_loop_engineer/review.py::blocking_findings`). |
| Gate command | The attempt worktree plus the scrubbed environment (`src/kickass_loop_engineer/guardrails.py::_gate_environment`). | Anything the engine's OS user can write: there is no sandbox, and the worktree's new files get promoted. | Only allowlisted programs, with no shell syntax, a timeout, and PATH folders inside the workspace skipped (`src/kickass_loop_engineer/guardrails.py::run`). | Its exit code is the pass verdict (`src/kickass_loop_engineer/verifier.py::run_gate`); a pass counts only if proof-of-test holds (`src/kickass_loop_engineer/verifier.py::prove`). |
| Engine | Everything in the main workspace and every worktree. | Creates worktrees and copies the winner's files into the workspace; deletions are never propagated (`src/kickass_loop_engineer/worktree.py::promote`). | Providers, gates, observers, git. Stops on protected paths, risky words, file and attempt caps (`src/kickass_loop_engineer/escalation.py::should_escalate`) and the cost cap (`src/kickass_loop_engineer/orchestrator.py::_run_slice`). | Declares SUCCESS only when the final gates pass (`src/kickass_loop_engineer/orchestrator.py::_process_slices`); keeps builder and reviewer in different families (`src/kickass_loop_engineer/review.py::ensure_cross_model`). |
| Meet | Every artifact under `.loop-engineer/` and the journal. | The YAML config, including extra allowlist prefixes (`src/kickass_loop_engineer/config.py::build_verification_policy`) and denylist exemptions (`src/kickass_loop_engineer/config.py::escalation_allow_tokens`). | The CLI (`src/kickass_loop_engineer/cli.py`). | Escalations: the engine ends in APPROVAL_REQUIRED (`src/kickass_loop_engineer/orchestrator.py::_run_slice`) and asks (`src/kickass_loop_engineer/next.py`); Meet re-runs with a changed config. Open questions go to [decisions.md](decisions.md#open-questions-for-meet). |

Binding of each item a proof rests on: [proof-binding.md](proof-binding.md).
